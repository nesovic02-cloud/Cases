# NeonCrates — демо-платформа открытия кейсов

Полноценный SPA на React + TypeScript + Vite с Tailwind UI. Включает главную страницу с hero-блоком, каталог кейсов, страницу конкретного кейса с анимацией рулетки, профиль с инвентарём и историей, FAQ и скрытую админку (вызов сочетанием `Ctrl + Alt + A`, пароль `admin123`).

## Возможности
- мок-авторизация пользователя, баланс в coins, хранение инвентаря и продажа предметов;
- взвешенный рандом выпадения предметов с визуальной анимацией и лентой последних дропов;
- редактирование кейсов и предметов в админ-панели, изменение весов (шансов), цен и статусов активности;
- простая статистика по открытиям и управление пользователями (баланс, блокировка);
- описанная концепция provably fair и архитектура для будущих интеграций API/Steam/платежей.

## Стек и запуск
```
npm install
npm run dev
```

> Установка пакетов требует доступа к npm-регистру. В демо окружении можно просто изучить код.
